統一編號驗證說明

這份頁面用白話說明專案中的統一編號驗證規則，也可以直接輸入 8 碼統編，即時查看是否符合規則。

簡單說

統一編號不是只檢查「是不是 8 碼數字」。它還會用一組固定權重做計算，確認這 8 碼是不是符合統一編號的檢核規則。

固定權重是：

第 1 碼1
第 2 碼2
第 3 碼1
第 4 碼2
第 5 碼1
第 6 碼2
第 7 碼4
第 8 碼1

規則

  1. 必須是 8 碼數字。
  2. 8 個數字分別乘上固定權重 1, 2, 1, 2, 1, 2, 4, 1。
  3. 如果乘出來是兩位數，要拆成「十位數 + 個位數」。例如 16 要算成 1 + 6 = 7。
  4. 把所有結果加總。
  5. 如果總和可以被 5 整除，就通過。

第 7 碼是 7 的特殊規則

第 7 碼不一定要是 7。只是當第 7 碼剛好是 7 時，會多一個放寬判斷：

總和 + 1 如果可以被 5 整除，也算通過。

專案中的程式碼

目前專案的判斷主要在 VerifyHelper.uniformNumber：

static uniformNumber(number: string) {
    if (number === undefined)
        return false;
    number = number.toString();
    if (number === "" || number.toString().length != 8)
        return false;
    let weight: number[] = [1, 2, 1, 2, 1, 2, 4, 1];
    let sum = 0
    for (let x = 0; x < weight.length; x++) {
        let j = Number(number[x]) * weight[x];
        sum += Math.floor(j / 10) + (j % 10);
    }
    if (sum % 5 === 0)
        return true;

    if (number.substring(6, 1) === "7") {
        if ((sum + 1) % 5 === 0)
            return true;
    }
    return false;
}
注意：如果目標是判斷第 7 碼，JavaScript 通常會寫成 number[6] === "7" 或 number.substring(6, 7) === "7"。上面專案原碼的 substring(6, 1) 看起來不像是正確取得第 7 碼。
