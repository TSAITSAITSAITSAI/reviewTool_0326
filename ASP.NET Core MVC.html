ASP.NET Core MVC 轉 Angular 培訓規劃

本規劃目標是讓同事先透過線上資源建立 Angular 基礎，再透過現有專案理解 MVC 與 Angular 的差異， 最後以小型 PoC 實作作為後續工時評估依據。

階段 天數 方式 目標 學習重點 產出
1. Angular 自學 1-3 天 同事自行利用線上資源學習 先理解 Angular 基本觀念，不要求精通 Component、Template、Binding、Routing、Service、HttpClient、Form、Observable 基礎 能看懂 Angular 專案結構，並做出簡單頁面
2. MVC vs Angular 對照說明 1 天 由你使用現有專案進行講解 讓同事理解舊專案轉 Angular 時的主要差異 .cshtml 對應 Component、ViewBag / Model 對應 State、jQuery AJAX 對應 HttpClient、PartialView 對應 Component / Modal、Controller 對應 API 一份轉換對照筆記
3. 實作 PoC 1-2 天 你帶同事用現有專案改一個小功能 實際體驗一頁 MVC 如何轉成 Angular Component 拆分、API 串接、表單送出、錯誤處理、登入與權限初步處理 一個可執行的 Angular 範例頁
4. 工時評估 0.5-1 天 同事自行評估，你協助校正 根據 PoC 推估全案轉換時間 頁面數量、功能複雜度、API 缺口、共用元件、測試與部署方式 初版轉換工時表
建議重點：這不是單純語法轉換，而是前後端架構轉換。後端 Service、DAO、Model 多數可保留， 但 Razor View 與 jQuery 前端互動通常需要重新設計為 Angular Component 與 Service。
